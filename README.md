Put your MP4 files in this folder.

The lesson buttons expect these filenames by default:
- lesson1.mp4
- lesson2.mp4
- lesson3.mp4

To use your own videos, either rename your files to match, or edit the
data-src / data-title / data-duration / data-desc attributes of the
buttons in index.html (the file names live in the "Lesson Player" section).

Tip: H.264 encoded MP4 files play in every current browser.
If a video does not load, the page shows a "Video file not found" notice
under the player.
